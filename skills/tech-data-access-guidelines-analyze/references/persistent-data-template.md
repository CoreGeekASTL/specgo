## 使用方式

### 现状

{连接与客户端管理：client 单例还是每请求新建，连接池配置（池大小、空闲、超时）与取值来源，初始化与关闭点所在文件；事务使用点：哪些写路径开事务、事务边界（起止位置、传播/嵌套）、跨表一致性处理，无事务如实写「代码未使用事务」；分页与批量：分页方式（limit/offset、游标、全量拉取）、批量读写（batch insert、bulk）、大数据量处理；SQL 拼接与注入防护：参数化 vs 字符串拼接分布、动态 SQL 构造点、ORM 原生 SQL 出口（Raw/Exec）——非 SQL 存储该子维度写「本存储不涉及」；附证据文件路径}

### 约定（起草待评审）

{如：client 一律经封装层单例获取，禁止业务代码自行 Open；多表写必须同事务，事务边界收在 dao 层；列表查询一律分页且单页上限 N；批量写走 batch 接口，禁止循环单条写入；查询条件一律参数化绑定，禁止 fmt.Sprintf 拼接值}
