### 现状

## 缓存读写模式

### 现状

{读写策略（Cache-Aside / Read-Through / Write-Through / Write-Behind）；key 命名与 TTL 设置；穿透处理（空值缓存/布隆过滤）；击穿处理（互斥重建/逻辑过期）；雪崩处理（TTL 抖动）；缓存与库一致性路径；附证据文件路径。非缓存中间件本维度写「本中间件不涉及」}。例：Cache-Aside——src/service/auth_cache.go 先查缓存，miss 后查库回写；TTL 10min 无抖动；空结果不回写（无穿透防护）。

### 约定（起草待评审）

{如：key 统一 {业务域}:{实体}:{id} 格式；所有 key 必须显式 TTL 并加随机抖动；空结果短 TTL 回写防穿透}
