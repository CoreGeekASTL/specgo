## 填写口径

- **打分**：通用分/专项分/总分按 SKILL.md「打分模型」计算（基准 100 扣分制，总分 = 通用 × 0.4 + 专项 × 0.6，保留 1 位小数）；分级 ≥95 已基线 / 80–95 待修订 / <80 重写，零容忍命中 ≥3 处直接「重写」。
- **报告列**：链接到对应 `{文档基名}-audit.md`；总览模式无单篇报告，写 `—（仅总览）`。
- **第 3 节**：仅总览模式保留——逐篇列出待修订/重写文档的失实证据与改进建议（替代单篇报告）；更新/全量模式省略本节。
- **模式差异**：更新模式只更新被审文档对应行（无则新增），第 1 节基于全部既有行重算；总览/全量模式三节全量重建。
