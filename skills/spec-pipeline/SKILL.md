# spec-pipeline — 流水线执行（查找并执行 pipeline-skill.md）

代码生成（spec-code-generate）完成、资产刷新（spec-update）之前的可选环节：调用流水线完成编译、出镜像、部署、端到端测试等流程。

**核心机制**：本 skill **不内置任何流水线步骤**——流水线的唯一事实来源是被分析项目中的 `pipeline-skill.md` 文档。本 skill 只定义查找、执行与汇报纪律。

**交互双模式（全局条款）**：本 skill 所有询问点**默认使用 ask-human 工具**；若任务开始时用户声明"以报告形式呈现"（或同类意思），则全程**不使用 ask-human**——待确认/待审视内容以报告形式输出，等用户回复后继续。

## 第 1 步：查找 pipeline-skill.md

1. 从**项目根目录**递归查找 `pipeline-skill.md`（排除 `node_modules/`、`vendor/`、`.git/`、`third_party/` 等目录）。
2. 按命中数量分支：
   - **0 个** → 明确告知"项目内无 pipeline-skill.md"，按双模式询问用户：跳过本环节，或提供文档路径。**禁止脑补流水线步骤。**
   - **1 个** → 直接使用。
   - **多个**（项目含多个代码仓时可能出现）→ 读取每个命中文档的**前 5 行**，结合当前需求涉及的代码仓自行选定最合适的一个，并告知用户选了哪个及选择理由。

## 第 2 步：解析与执行前确认

1. 读取选定文档**全文**，解析其定义的阶段序列（如编译 → 出镜像 → 部署 → E2E）与每阶段的命令、工作目录、成功判据。
2. **执行前确认门**：把「选定文档路径 + 将执行的阶段与命令清单」完整列出，按双模式交用户过目——默认 ask-human 确认；报告模式列入前置报告等用户回复。**未经确认不执行任何命令。**

## 第 3 步：派单个子代理跑完整条流水线

1. **只开启一个子代理**承担整条流水线：该子代理读取选定文档全文后，按文档定义的阶段顺序**一次跑完全部阶段**（编译/出镜像/部署/E2E 等，阶段间串行是文档自身的语义，由该子代理按文档执行）。
2. 子代理 prompt 必含：选定文档绝对路径（先读全文再开工）、工作目录、执行纪律（严格按文档阶段与命令执行，文档外命令一律不执行）、返回要求（总报告：各阶段命令原文/退出码/关键日志摘要/耗时/产物信息如镜像 tag/部署地址/E2E 用例级结果）。
3. **失败即停**：子代理在任一阶段失败即停止后续阶段，把现场（失败阶段与命令、退出码、日志尾部、已完成阶段清单）写入总报告返回；主代理原样呈交用户决策——**不擅自重试、不擅自跳过、不派新子代理补救**。
4. 主代理不亲自执行流水线命令，也不拆阶段派多个子代理。

## 第 4 步：流水线总报告（不落盘，收尾必做）

子代理返回后，主代理原样汇总呈现总报告（不落盘；用户要求时可落盘）：

```
# 流水线执行报告
1. 执行依据：选定 pipeline-skill.md 路径（多份时的选择理由）
2. 阶段结果明细：阶段名 | 命令 | 结果 | 耗时 | 产物（镜像 tag / 部署地址 / 测试报告路径等）
3. E2E 测试结果：用例级通过情况（到用例步骤级）
4. 失败现场（如有）：失败阶段/命令/退出码/日志尾部/已完成阶段清单
5. 下一步建议：可进入 spec-update 资产刷新
```

报告呈现后按双模式完成用户审视（默认 ask-human，报告模式仅输出）。

## 红线

| 想法 | 现实 |
|---|---|
| "没有 pipeline-skill.md，我按常规 CI 流程跑一遍" | 流水线步骤的唯一来源是 pipeline-skill.md，找不到就问用户，禁止脑补 |
| "每个阶段派一个子代理，干净" | 只开启一个子代理跑完整条流水线并出总报告，不拆阶段 |
| "命令我主代理顺手跑了" | 流水线命令由子代理执行，主代理只解析、确认与验收汇报 |
| "这个阶段失败了我重试一次" | 失败即停，现场写进总报告交用户决策，不擅自重试/跳过/派新子代理补救 |
| "文档没写的清理命令我补一条" | 文档外命令一律不执行 |
| "直接开跑，跑完再汇报" | 执行前确认门不过，不执行任何命令 |

## 与其它 skill 的关系

- **spec-code-generate**：上游——代码实现与本地测试完成后进入本 skill。
- **spec-update**：下游——流水线通过后做资产刷新收口。
- **mermaid-validate**：无关系（本 skill 不产出含图文档）。
